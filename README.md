# E-commerce ETL Pipeline

## Project Overview

This project focuses on building an end-to-end E-commerce ETL pipeline using Python, Pandas, and PostgreSQL.

The goal is to extract data from multiple CSV files, perform data cleaning and transformation, and load the processed data into PostgreSQL.

## Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Git and GitHub

## Architecture

The project will follow the Medallion Architecture:

- **Bronze:** Raw data storage.
- **Silver:** Cleaned and transformed data.
- **Gold:** Business-ready dimensional models.
